# SoranFrench App

A mobile application for learning French, built with Jetpack Compose.

## Overview

SoranFrench App is an Android application designed to help users learn French through interactive lessons and exercises. The app is built using modern Android development technologies including Kotlin and Jetpack Compose.

## Features

- Modern UI built with Jetpack Compose
- Material 3 design implementation
- Edge-to-edge content display

## Tech Stack

- **Language**: Kotlin
- **UI Framework**: Jetpack Compose
- **Architecture**: MVVM (Model-View-ViewModel)
- **Minimum SDK**: 26 (Android 8.0 Oreo)
- **Target SDK**: 35 (Android 15)

## Development Setup

### Prerequisites

- Android Studio Iguana or newer
- JDK 11 or higher
- Android SDK with API level 35

### Building the Project

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/SoranFrenchApp.git
   ```

2. Open the project in Android Studio.

3. Sync the project with Gradle files.

4. Build and run the application on an emulator or physical device.

## Project Structure

- `app/src/main/java/com/berbersoft/soranfrenchapp/` - Main source code
  - `ui/theme/` - Theme configuration for the application
  - `MainActivity.kt` - Entry point of the application
